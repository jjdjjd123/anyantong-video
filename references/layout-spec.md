# 布局与样式规范

画布 1920x1080，FPS 30。坐标均基于该画布。**垂直顺序固定，禁止调换**。

## 垂直顺序（硬约束）

1. 顶部：品牌胶囊 → 主标题 → 副标题
2. 阶段标题 + 分阶段信息条（左侧让位数字人）
3. 安全状态芯片
4. 底部字幕条

芯片必须位于信息条下方、字幕上方。禁止把芯片放回底部，禁止在左侧数字人区域加深色填充。

## 阶段切换

信息条按帧数平均分配：frames_per_stage = total_frames // stage_count，当前阶段 = frame_idx // frames_per_stage（最后阶段钳制在末尾）。每阶段首尾各 8 帧做淡入淡出，alpha 下限 100。

## 背景叠加 prepare_background

cover 裁剪到 1920x1080 → 亮度 x1.05 → 对比度 x1.03 → 叠加下列 RGBA：

- 全屏 (2,8,26,100)
- 全屏 (4,14,34,25)
- 椭圆 (600,50,1800,800) 色 (36,126,200,28)
- 椭圆 (-200,650,700,1250) 色 (255,138,43,14)
- 右侧竖条 (1620,0,W,H) 色 (2,8,26,24)

**禁止**在左侧数字人区域再加暗化矩形，会与留白边框叠加成黑块。
